## Featured Projects

### [RDM-Server](https://github.com/tashkirrr/RDM-Server)
A Redis-like in-memory key-value store built from scratch in Go.

- Master-slave replication with automatic discovery
- AOF persistence for crash recovery
- Custom RESP parser with memory attack protection
- Redis Streams support (XADD, XREAD)
- Zero dependencies — built entirely with Go's standard library

**Tech:** Go, Distributed Systems, TCP Networking, Binary Protocols

---
